# Career Stories Prototype (Example Project)

A small responsive example career-exploration website prototype built with HTML, CSS, and JavaScript.

## Features

- Search through example career stories by role, interests, skills, or major
- Filter stories by career field, experience level, and interest
- Open a story modal to read more about a sample career journey
- Reset filters and view a responsive layout on mobile and desktop

## Files

- `index.html` — page structure and links to the stylesheet and JavaScript
- `style.css` — colors, layout, responsive styles, and modal styling
- `script.js` — fictional sample data, search/filter behavior, and story modals

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `career-stories-prototype`).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the published URL will appear in the Pages settings.

## Important notes

This is an AI-assisted concept prototype, the sample career profiles are fictional and for demonstration only. The project currently uses static data in `script.js`; it does not connect to a CMS, database, or a real career-story submission system. This project was created as an example.
